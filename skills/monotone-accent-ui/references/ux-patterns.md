# UX 패턴 — 화면을 어떻게 구성하는가

토큰·컴포넌트가 "무엇으로 그리는가"라면, 이 문서는 **"어떻게 배치하고 흐르게 하는가"** 다.
개인 기록/계획 관리 앱을 실사용하며 수렴한 구조로, 도메인 이름만 바꾸면 대시보드형 앱 대부분에 적용된다.

---

## 0. 관통하는 원칙 5개

1. **"지금"이 1급 시민.** 오늘·현재 시각·다가오는 일정이 항상 첫 화면 위쪽에 있고, 저장된 스크롤·선택보다 우선한다.
2. **수집 → 실행 → 보관의 3단 흐름.** 아무 데나 적는 수집함, 오늘 할 것만 남는 실행 영역, 지나간 것이 쌓이는 보관소를 **분리**한다. 사용자는 옮기기만 한다.
3. **모든 블록은 자급자족 카드.** 카드마다 자기 추가 입력·자기 액션을 갖는다. 다른 화면으로 이동하지 않고 그 자리에서 끝난다.
4. **삭제 대신 이동·보관.** 파괴적 동작을 기본 동선에서 제거한다(어제로 보내기, 아카이브, 숨기기).
5. **빈 상태가 다음 행동을 지시한다.** "비어 있습니다"로 끝내지 않고 무엇을 누르면 되는지 한 문장으로 말한다.

---

## 1. 허브 + 페이저 (블록 대시보드)

**구조** 세로로 쌓인 카드 블록들 + 상단 중앙의 페이지 도트. 활성 도트는 알약처럼 **가로로 늘어나며 라벨을 노출**하고, 비활성은 작은 점만.

```
[ 티커 / 상단 알림 바 ]
        ● ▬▬ 목표·할 일          ← 활성 도트만 라벨 표시
[ 카드 ]
[ 카드 ]
```

**규칙**
- 페이지는 2~3개까지. 그 이상은 탭이나 별도 라우트로.
- 블록 배치·높이는 저장하되, 편집 모드에서만 드래그 재배치를 허용한다(평소 클릭과 충돌 방지).
- 현재 페이지 번호도 저장한다. 단, 외부에서 특정 항목으로 이동을 요청하면(검색 등) 저장값을 무시하고 그 페이지로 전환한다.

**WHY** 스크롤이 길어지면 아래쪽 블록은 존재하지 않는 것과 같다. 페이저는 "덜 중요한 것을 지우지 않고 접는" 방법이다.

---

## 2. 히어로 카드 — "지금"을 한 카드에

**구조** 첫 카드 하나에 시계·오늘 날짜·다가오는 일정(D-N)·미니 캘린더·빠른 일정 추가를 함께 넣는다. 좌: 시간과 임박 목록, 우: 달력.

**규칙**
- D-N은 `D-DAY` / `D-5` 형태로 왼쪽 고정 폭에 두고 제목은 `text-overflow: ellipsis`.
- 임박한 것(예: 7일 이내)만 액센트 색, 나머지는 기본 텍스트색 — **색이 아니라 임계값으로** 구분.
- 미니 캘린더의 오늘은 solid accent 원, 일정 있는 날은 아래 4px 점.

---

## 3. 카드 헤더 규약

```
[아이콘 칩] 제목  개수      ……      [액션 알약] [액션 알약] [편집]
```

- 아이콘 칩 = 30px 정사각 + accent 14% 배경 (전역 skill P1).
- 개수는 제목 옆에 `--text-muted`로 작게. 0이어도 표시한다(비어 있음을 숨기지 않는다).
- 액션은 오른쪽 정렬 알약 묶음, `flexWrap` 필수. 파괴적 액션은 오른쪽 끝.
- 편집 모드가 있는 카드는 `편집` ↔ `편집 완료` 토글 하나로 진입/이탈한다. 편집 모드에서만 삭제·순서 변경 UI가 나타난다.

---

## 4. 시간 3구간 섹션 (어제 / 오늘 / 내일)

**구조** 접이식 섹션 3개. 기본 펼침은 **오늘만**. 섹션 헤더에 개수와 일괄 이동 버튼(`▲위` `▼아래`), 활성 섹션에는 `FOCUSING` 같은 상태 라벨.

**규칙**
- 자정을 넘기면 오늘→어제, 내일→오늘로 자동 이월하고 **완료분은 보관소에 먼저 기록**한다. 어제 것은 그때 정리한다.
- 항목별 이동 버튼(어제로/내일로)과 섹션 단위 일괄 이동을 **둘 다** 제공한다.
- 완료 항목은 `line-through` + `opacity 0.5`, 숨기기 토글은 섹션 헤더에.
- 접힘 상태는 저장하되 오늘은 항상 펼친 상태로 시작한다.

**WHY** "어제 못한 것"이 보이지 않으면 그냥 사라진다. 3구간은 미완료를 삭제하지 않고 흘려보내는 장치다.

---

## 5. 수집함 → 오늘 끌어오기

**구조** 실행 영역 위에 별도의 수집 카드(`전체 할 일`)를 둔다. 여기에는 날짜가 없다. 항목마다 `오늘로` 버튼.

빈 상태 문구 예: *"아직 모아둔 할 일이 없어요. 위에 적어서 쌓아두고 '오늘로' 가져오세요."* — 빈 상태가 흐름을 설명한다.

**WHY** 떠오른 일을 바로 오늘에 넣으면 오늘이 무한정 불어난다. 수집과 선택을 분리하면 오늘 목록이 **의도적으로 고른 것**만 남는다.

---

## 6. 커맨드 팔레트형 전역 검색

**구조** 화면 상단 1/4 지점에 뜨는 오버레이 패널. 뒤 배경은 어둡게 + 살짝 블러. 입력 오른쪽에 `Esc` 칩과 X.

**규칙**
- 단축키 `⌘/Ctrl + K`, 안내 문구에 그대로 노출한다.
- placeholder에 **검색 대상 목록**을 적는다: `전체 검색 — 메모·아카이빙·일기·파일·일정…` (무엇이 검색되는지가 곧 앱의 지도)
- 결과를 고르면 그 화면으로 이동하는 것으로 끝내지 않고, **접혀 있던 표면이 스스로 열리고 해당 텍스트가 하이라이트**돼야 한다(전역 이벤트 브로드캐스트 → 각 표면이 자기 것을 열기).
- 결과가 없을 때도 패널 높이를 유지해 레이아웃이 튀지 않게 한다.

## 7. 페이지 헤더 (상세 화면)

```
Home / 2026 / August 2026            [⋯]
[기록] [계획]                         ← 세그먼트로 모드 전환
2026 August 기록                      ← 큰 제목(1.9rem+, weight 900)
```

- 브레드크럼은 계층 이동, 세그먼트는 **같은 데이터의 다른 모드**(기록/계획) 전환. 둘을 섞지 않는다.
- 우측 `⋯`는 파괴적·드문 액션 전용(내보내기·초기화). 자주 쓰는 액션은 절대 여기 넣지 않는다.

---

## 8. 통계 / 요약 블록

- **스탯 타일 3열**: 각 타일은 `라벨 + 큰 숫자`. 값이 없으면 `기록 없음`을 회색으로 (0을 억지로 만들지 않는다).
- **최근 7일 표**: `DAY / SUMMARY / 상태` 3열, 날짜는 요일 + 월/일 2줄.
- **연간 히트맵**: 7×n 격자, 값 없음은 `text-muted 6%`, 값은 액센트 농도 4단계. 오늘 칸만 1.5px accent 테두리.
- 숫자는 전부 `tabular-nums`. 퍼센트는 정수로 반올림.

---

## 9. 진행률 행 (목표)

```
제목                          ~2026   40%
▬▬▬▬▬▬▬▬▬░░░░░░░░░░░░░░░░
```

- 한 행 = 제목 + (기한 칩) + % + 하단 진행 바. 바는 트랙 `text-main 6%`, 채움은 solid accent.
- 카드 헤더에는 **평균 진행률**을 표시해 전체 감을 준다.
- 목록 맨 위에 인라인 추가 입력을 둔다(`새 목표를 걸어두세요…` + `+`).

## 10. 상시 표면 3종

| 표면 | 위치·행동 |
|---|---|
| **티커** | 최상단 가로 바. 진행 중인 것이 없으면 `+ 추가` 유도 문구만 남긴다(빈 바를 그냥 두지 않는다) |
| **FAB** | 우측 하단 고정 원형 버튼, 어느 화면에서나 빠른 작성 진입. 스크롤해도 위치 고정 |
| **알림 벨** | 상단 우측, 안읽음이 있으면 점 배지. 항목은 안읽음 → 다시보기(보관) / 읽음(퇴장) 3상태 |

**규칙** 세 표면 모두 **자동으로 튀어나오지 않는다.** 자동으로 뜨는 것(알림 팝업 등)에는 반드시 억제 옵션을 준다.

---

## 11. 인라인 편집 문서 (메모·일기)

- 평소에는 **렌더된 마크다운**, 클릭(또는 더블클릭)하면 그 자리에서 편집으로 전환, blur/Esc로 복귀. 별도 편집 화면 없음.
- 긴 글은 접기 임계 높이(예: 600px)를 넘을 때만 `더보기`/`접기` 버튼을 노출한다. 짧은 글에는 버튼이 아예 없다.
- 임계값은 상수 하나로 두고, 노출 판정·검색 자동 펼침 판정이 **같은 상수**를 참조하게 한다.
- 자동저장. "저장" 버튼을 요구하지 않는다.

---

## 12. 데스크톱 위젯 (Electron 등)

- 프레임리스 + always-on-top 작은 창으로 **핵심 블록만** 떼어낸다(시계·달력·일정·보드).
- 자체 타이틀바에 핀 토글과 닫기. 본체와 같은 저장소를 보므로 한쪽에서 바꾸면 즉시 반영된다.
- 위젯은 **별도 렌더 경로**다 — 본체 UI를 고칠 때 위젯도 검토 목록에 포함시킨다(전역 skill P3-6).

## 13. 빈 상태 문구 규칙

| 나쁨 | 좋음 |
|---|---|
| `데이터 없음` | `항목 옆의 ★를 눌러 오늘 할 일을 골라보세요.` |
| `비어 있습니다` | `아직 모아둔 할 일이 없어요. 위에 적어서 쌓아두고 '오늘로' 가져오세요.` |
| (아무것도 안 보임) | `습관을 추가해 보세요. (일기·갱신·만족도 자동 습관도 선택 가능)` |

- 문구는 `--text-muted` + `opacity 0.75`, 카드 안쪽 중앙 정렬, 1줄.
- **다음에 누를 것을 지목**한다. 기능 설명이 아니라 행동 지시.
